# Бункер — браузерная игра

Мобильная браузерная игра для компании до пяти человек. Два независимых сеттинга: современность и фэнтези.

## Что уже есть в первой версии
- Адаптивный интерфейс для телефона и компьютера.
- Выбор сеттинга и числа игроков (3–5).
- Раздача 9 карт каждому: пол/возраст, здоровье, профессия, хобби, два факта, особое условие, лёгкий и тяжёлый багаж.
- Уникальная раздача экземпляров: у каждой карты есть лимит `copies`, экземпляр удаляется из общего пула после выдачи.
- Каталог карт с поиском, фильтром по сеттингу и категориям.
- Особые условия хранятся в руке и применяются игроком вручную — автоматического срабатывания при раздаче нет.
- В фэнтези-здоровье включает обычные болезни и магические недуги.

## Важно: текущий статус
Это **локальный прототип**: комнаты и карты пока живут в памяти одного открытого браузера. Код комнаты пока демонстрационный; подключение с разных телефонов ещё не работает. Для полноценной сетевой игры следующим этапом подключается Supabase: таблицы комнат/участников/колод, серверная функция атомарной раздачи и realtime-обновления. Нельзя хранить секретный service-role ключ в клиентском коде или GitHub Pages.

## Запуск
Откройте `index.html` в браузере или опубликуйте корень ветки `main` через GitHub Pages.

## Публикация через GitHub Pages
1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем Save.
4. Дождитесь завершения публикации и откройте адрес, указанный в Settings → Pages.

## Структура
- `index.html` — интерфейс.
- `styles.css` — адаптивное оформление.
- `cards.js` — оригинальные колоды и лимиты экземпляров.
- `app.js` — локальная логика прототипа.
- `supabase/schema.sql` — начальная схема будущего сетевого режима.

Карты — оригинальный контент проекта, вдохновлённый жанром игр на выживание и обсуждение кандидатур; это не копирование коммерческих колод.
