# Бункер — генератор наборов карт

Мобильная браузерная игра/генератор для компании. Два сеттинга: современность и фэнтези.

## Как пользоваться
1. Откройте сайт и нажмите **Современность** или **Фэнтези** — сразу появится случайный личный набор из 9 карт.
2. Нажмите **Перемешать набор**, чтобы получить другую комбинацию.
3. Отдельными кнопками открывайте общие карты: одну катастрофу, до двух угроз и до трёх преимуществ бункера.
4. Чтобы начать новый сценарий, выберите сеттинг ещё раз: личный набор и открытые сценарные карты будут сгенерированы заново.
5. В каталоге можно посмотреть все карты выбранного сеттинга.

## Личный набор
- Пол и возраст
- Здоровье
- Профессия
- Хобби
- Два факта
- Особое условие
- Лёгкий багаж
- Тяжёлый багаж

Набор формируется случайно, по одной карте из каждой нужной категории и две карты из категории «Факт». Экземпляры учитывают поле `copies`.

## Общие сценарные карты
- **Катастрофа** — одна на партию. Помимо описания, каждая карта показывает тип угрозы, ориентировочный срок ожидания и условие, при котором можно безопасно выходить.
- **Угрозы** — до двух разных карт на партию.
- **Преимущества бункера** — до трёх разных карт на партию.

Катастрофа, угрозы и преимущества не входят в личные девять карт.

## Важно
Это локальный генератор: каждый браузер выбирает карты независимо. Наборы и открытые события не синхронизируются между разными телефонами. Для общей онлайн-игры потребуется серверная комната.

## Структура
- `index.html` — интерфейс.
- `styles.css` — адаптивное оформление.
- `cards.js` — колоды и данные катастроф.
- `app.js` — генерация и отображение наборов.
- `supabase/schema.sql` — заготовка будущего сетевого режима.
